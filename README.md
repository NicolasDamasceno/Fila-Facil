# Fila Fácil - entrega individual

**Objetivo:** protótipo didático de emissão e chamada de senhas em ordem FIFO.

**Origem:** Lab 02 da disciplina TEC.1053 (IFPI), [github.com/aislanifpi/tec1053](https://github.com/aislanifpi/tec1053). Código original sob licença MIT (ver `LICENSE`).

**Integrantes:** Nicolas Damasceno

**Aplicação:** https://nicolasdamasceno.github.io/Fila-Facil/

**Testes:** https://nicolasdamasceno.github.io/Fila-Facil/tests/index.html

**Tarefa e evidências:** https://github.com/NicolasDamasceno/Fila-Facil/issues/1

**Como executar localmente:** abrir `index.html` e `tests/index.html`.

**Limites:** fila por aba, estado em memória, recarga apaga a sessão, sem backend, persistência, sincronização ou dados reais.
